# Smart Memo 智忆单词学习系统用户手册

## 第一章 系统简介

### 1.1 产品概述

Smart Memo（智忆单词）是一款基于艾宾浩斯遗忘曲线理论开发的智能英语单词学习系统。该系统采用 Vue 3 前端框架构建，提供了流畅的单页应用体验，同时利用 Supabase 云数据库实现数据的实时同步，确保用户在任何设备上都能获得一致的学习进度。

本系统主要面向两类用户群体：一是教育机构的管理人员和教师，他们负责词库内容的管理和学生学习进度的监控；二是学生用户，他们通过系统进行单词学习和复习巩固。系统采用响应式设计，完美支持桌面端和移动端设备，让学生可以随时随地进行学习。

智忆单词的核心竞争力在于其智能化的学习算法。系统会根据每个学生对每个单词的掌握程度，自动调整复习时间间隔。对于掌握较好的单词，复习间隔会逐渐延长；对于掌握不牢的单词，系统会频繁安排复习，帮助学生强化记忆。这种个性化的学习方式比传统的死记硬背效率高出数倍。

### 1.2 主要功能模块

**管理端（教师/管理员）** 功能模块包括：仪表盘概览、词库管理、用户管理、学习计划设置、统计分析等。教师可以通过仪表盘快速了解整体学习情况，通过词库管理模块添加和编辑单词，通过用户管理模块分配学习任务，通过统计分析模块了解学生的学习效果。

**学生端** 功能模块包括：学习中心、单词本、导入单词、个人中心等。学生可以在学习中心完成每日的学习和复习任务，在单词本中查看所有已学单词，在导入单词中添加到个人词库，在个人中心查看学习统计和调整设置。

### 1.3 系统环境要求

系统推荐使用以下浏览器访问以获得最佳体验：Google Chrome（版本 90 及以上）、Microsoft Edge（版本 90 及以上）、Mozilla Firefox（版本 88 及以上）、Safari（版本 14 及以上）。请确保网络连接稳定，系统需要持续访问互联网以同步学习数据和获取在线资源。

## 第二章 快速开始

### 2.1 账号注册与登录

首次使用系统的第一步是注册账号。访问系统首页后，点击“注册”按钮进入注册页面。您可以选择使用邮箱注册或使用已有的社交账号快捷登录。填写必要的注册信息后，系统会向您的邮箱发送验证链接或验证码，请按照提示完成验证流程。

登录时，在首页输入注册时使用的邮箱和密码，点击登录按钮即可进入系统。如果忘记密码，可以点击“忘记密码”链接，通过绑定的邮箱接收重置链接。登录成功后，系统会自动跳转到对应角色的主页：管理员进入管理端，学生进入学习中心。

### 2.2 界面布局说明

进入系统后，您会看到清晰的界面布局。顶部是系统标题和当前登录用户的信息，点击用户名可以进入个人中心或退出登录。左侧（桌面端）或底部（移动端）是导航栏，包含系统的主要功能入口。中间区域是内容显示区，根据您选择的功能模块显示相应的内容。

导航栏的设计遵循功能相关性原则，相关联的功能被组织在一起。管理端的导航通常包括仪表盘、词库管理、用户管理、学习计划、统计分析等入口；学生端的导航则包括今日学习、单词本、导入单词、我的收藏、学习统计等入口。

## 第三章 管理端功能详解

### 3.1 仪表盘

仪表盘是管理员登录后的默认首页，提供了系统运行的核心数据概览。在这个页面，您可以快速了解当前的学习整体状况，包括注册用户总数、活跃用户数量、今日学习人数、累计学习单词数等关键指标。

仪表盘还展示了最近的学习动态列表，显示哪些学生最近有学习记录。这个列表是实时更新的，让您能够及时掌握学生的学习活跃度。如果您想查看某个学生的详细学习情况，可以点击列表中的学生头像或姓名，跳转到该学生的详细统计页面。

在仪表盘的显著位置，您可以看到本周的学习趋势图表，以折线图的形式展示过去七天的每日学习人数变化。这个图表帮助您了解学习的周期性规律，便于在低潮期采取措施激励学生学习。

### 3.2 词库管理

词库管理是管理端最重要的功能之一，教师在这里管理和维护所有教学词汇资源。进入词库管理页面后，您可以看到现有的词库列表，默认包含 CET-4、CET-6 等常用词库，您也可以根据需要创建新的词库。

**创建新词库**：点击“新建词库”按钮，在弹出的对话框中输入词库名称，如“考研英语词汇”、“雅思核心词汇”等。您可以为新词库设置说明文字，描述该词库的适用场景和目标人群。创建完成后，新词库会立即出现在词库列表中。

**添加单个单词**：在词库管理页面，点击“添加单词”按钮或点击某个词库进入单词列表后点击添加按钮，可以手动添加单个单词。添加单词时需要填写以下字段：单词拼写（必填）、词性（如名词 n.、动词 v. 等）、中文释义、音标、例句。系统会自动验证单词拼写的正确性，如果拼写有误会提示修改。

**批量导入单词**：手动逐个添加单词效率较低，批量导入功能可以帮助您快速添加大量单词。点击“批量导入”按钮，选择要导入的文件，系统支持 Excel（.xlsx、.xls）和纯文本（.txt）格式。Excel 文件需要按照规定的模板格式填写，第一行是表头，后续每行对应一个单词。导入前建议先下载系统提供的模板文件，按照模板格式准备数据可以提高导入成功率。

**编辑和删除单词**：在单词列表中，每个单词都有编辑和删除操作按钮。点击编辑可以修改单词的任意信息；点击删除会弹出确认对话框，确认后该单词将被永久删除，请谨慎操作。

**批量更新例句**：如果您的词库中缺少例句，可以使用批量更新例句功能。这个功能需要配置 DeepSeek API Key，配置后系统会自动为缺少例句的单词生成英文例句。注意使用此功能会产生 API 调用费用，请根据实际需求合理使用。

### 3.3 用户管理

用户管理页面展示了系统中所有注册用户的信息，包括学生和教师。管理员可以在这里进行用户账号的创建、编辑、删除和禁用等操作，也可以为学生分配学习词库。

**查看用户列表**：用户列表以表格形式展示，显示用户名、邮箱、身份角色、注册时间、最后登录时间等信息。您可以通过搜索框根据用户名或邮箱快速定位特定用户，也可以使用筛选器根据角色或注册时间范围筛选用户。

**分配学习词库**：这是用户管理的核心功能之一。点击某个学生的“分配词库”按钮，选择要分配给该学生的词库（可以多选），学生登录后就会在单词本中看到被分配的词库内容。分配词库后，学生可以选择学习全部被分配的词库，也可以设置只学习特定词库。

**设置每日学习量**：在用户详情页面，管理员可以设置学生每天需要学习的新词数量。这个设置会影响学生每日学习任务的生成，合理的每日学习量可以帮助学生保持稳定的学习节奏。

### 3.4 学习计划

学习计划功能允许教师为学生制定个性化的学习任务。与简单的词库分配不同，学习计划可以精确控制每个词库每日的新词学习数量，让学生能够同时学习多个词库的内容。

**创建学习计划**：在学习计划页面，点击“新建计划”按钮，选择目标学生和词库，设置每日学习数量（每日新词上限），还可以设置优先级（当多个计划有冲突时的优先级顺序）。计划创建后立即生效，学生次日的学习任务中就会包含该计划的内容。

**管理学习计划**：每个学习计划都可以单独暂停、恢复或删除。暂停计划后，学生暂时不会收到该计划的学习任务，但已学习的进度会保留。恢复计划后，学生继续按照原计划学习。删除计划会清除该计划的所有设置，请谨慎操作。

### 3.5 统计分析

统计分析页面提供了丰富的学习数据分析功能，帮助教师了解教学效果和学生学习状况。

**班级整体分析**：选择特定的班级或全部学生，查看整体的学习数据。包括：平均学习天数、平均掌握单词数、遗忘率分析、学习完成率等。这些数据可以帮助教师评估教学效果，发现存在的问题。

**个人学习详情**：选择某个学生，查看该学生的详细学习记录。包括：学习日历（每天的学习情况）、各词库的学习进度、记忆曲线变化、错题本内容等。通过这些数据，教师可以针对性地给予学生辅导。

**数据导出**：统计分析页面支持将数据导出为 Excel 文件，方便您在本地进行进一步分析或制作报表。导出内容可以自定义选择字段和日期范围。

## 第四章 学生端功能详解

### 4.1 今日学习

今日学习是学生端的核心功能，也是每天必用的功能。登录系统后会自动进入今日学习页面，这里展示当天需要学习的全部内容。

**学习任务构成**：每日的学习任务由两部分组成——新词学习和复习巩固。新词是指之前从未学习过的单词；复习是指之前学习过但还未完全掌握的单词。系统会根据艾宾浩斯遗忘曲线算法，计算每个单词的最佳复习时间，确保在记忆衰退前安排复习。

**学习流程**：开始学习后，系统会以卡片形式展示单词。卡片正面显示单词和音标，学生可以点击发音按钮聆听正确读音。点击卡片可以翻转，查看中文释义和英文例句。根据对单词的掌握程度，选择“陌生”、“模糊”、“认识”或“掌握”按钮。不同的选择会影响下次复习的时间间隔：选择“陌生”会在很短时间内再次出现，选择“掌握”则可以延长复习间隔。

**学习进度**：页面顶部显示当天的学习进度，包括已完成数量和总数量。完成当天的全部学习任务后，系统会显示学习完成提示，并展示本次学习的统计数据。

### 4.2 单词本

单词本相当于学生的个人词库，存储了所有被分配的单词和自己导入的单词。在单词本页面，学生可以浏览、搜索、编辑和删除单词。

**标签筛选**：单词本顶部提供多个标签用于筛选，包括：全部、教师布置（老师分配的词库）、自行导入（自己添加的单词）、新词、学习中、熟悉、掌握。通过点击不同标签，可以快速查看特定类型的单词。

**搜索功能**：如果单词较多，可以使用搜索功能快速定位。输入单词的英文或中文释义，系统会实时过滤显示匹配的结果。

**查看详情**：点击任意单词卡片，可以查看该单词的详细信息，包括音标、完整释义、例句、掌握程度等。在详情页面还可以播放发音或开始背诵该单词。

**编辑和删除**：对于自己导入的单词，学生可以编辑修改单词信息或删除。点击单词卡片上的编辑按钮可以修改单词内容；点击删除按钮并确认后，单词会被从个人词库中移除。教师布置的单词不能被删除，只能查看。

### 4.3 导入单词

导入单词功能允许学生添加自己感兴趣的单词到个人词库。这个功能特别适合学有余力的学生，他们可以自主扩展词汇量。

**手动添加**：在导入单词页面，可以逐个添加单词。输入英文单词后，系统会自动从词典 API 获取音标、释义和例句。如果某些信息获取失败，也可以手动填写补充。添加前系统会验证单词拼写的正确性，如果拼写有误会提示错误。

**批量导入**：如果需要一次性添加大量单词，可以使用批量导入功能。上传 Excel 或文本文件，系统会解析文件内容并批量添加单词。文件格式要求与教师批量导入相同，可以使用系统提供的模板文件。

**API 配置**：系统支持配置 DeepSeek API Key 来增强例句获取能力。配置后，即使词典 API 无法获取例句，系统也可以使用 AI 生成例句。这个配置是可选的，不配置也可以正常使用基本功能。

### 4.4 个人中心

个人中心是查看个人信息和调整设置的入口。在个人中心，学生可以查看学习统计、修改设置、管理收藏夹等。

**学习统计**：个人中心展示了详细的学习统计数据，包括：累计学习天数、总学习单词数、当前连续学习天数、最长连续学习天数、各词库的学习进度等。还有可视化图表展示记忆曲线和每周学习情况。

**学习设置**：在设置页面，学生可以调整每日学习量。新词数量设置决定了每天会收到多少新词学习任务，建议根据自己的时间和能力合理设置。设置过低会导致学习进度缓慢，设置过高则可能造成负担过重难以坚持。

**主题设置**：系统支持浅色和深色两种主题模式。深色模式可以在光线较暗的环境下保护眼睛，适合夜间学习时使用。点击主题切换按钮即可在两种模式间切换。

## 第五章 常见问题解答

### 5.1 账号与登录问题

**忘记密码怎么办**：如果忘记了登录密码，可以在登录页面点击“忘记密码”按钮，输入注册时使用的邮箱地址。系统会向该邮箱发送密码重置链接，点击链接后设置新密码即可。如果收件箱没有收到邮件，请检查垃圾邮件文件夹，有时邮件会被误判为垃圾邮件。

**收不到验证码怎么办**：注册或找回密码时需要输入邮箱收到的验证码。如果收不到验证码，请首先确认邮箱地址填写正确，然后检查垃圾邮件文件夹。某些邮箱服务商可能会拦截系统发送的邮件，可以尝试将发件地址加入白名单。如果持续无法收到，建议更换其他邮箱尝试。

**账号已被禁用怎么办**：如果登录时提示账号已被禁用，请联系系统管理员了解原因并申请恢复。账号被禁用通常是因为违反使用规范或长期欠费（如果是付费版）等原因。

### 5.2 数据同步问题

**多设备登录数据是否同步**：是的，系统采用云端存储架构，所有学习数据都保存在云端。在任何设备上登录账号，都会自动同步最新的学习进度和设置。您可以在手机上开始学习，然后在电脑上继续，过程完全无缝。

**为什么学习记录没有保存**：请确保在网络连接正常的环境下学习。网络中断时，本地会缓存学习数据，但需要在重新联网后才能同步到云端。如果确认网络正常但数据仍未同步，请尝试刷新页面或重新登录。

### 5.3 学习相关问题

**为什么认识的单词还会出现**：这是艾宾浩斯遗忘曲线的正常现象。系统会根据您对单词的掌握程度安排复习，即使当时选择了“掌握”，经过一定时间后系统仍会安排复习以巩固记忆。随着掌握程度的提高，复习间隔会越来越长，最终您会感觉单词“消失”了，实际上是被长期记住了。

**每日学习量可以调整吗**：可以。在个人中心的设置页面，您可以随时调整每日新词数量。减少数量会降低每日学习负担，增加数量会加快学习进度。建议根据实际可支配的学习时间合理设置。

**如何重置学习进度**：在个人中心设置页面底部，有“重置所有学习进度”的选项（学生端）。点击后系统会提示确认，确认后所有学习记录将被清除，您将重新开始学习。请注意这个操作不可恢复，请谨慎操作。

### 5.4 技术问题

**浏览器不兼容怎么办**：系统推荐使用 Chrome、Edge、Firefox 或 Safari 的最新版本。如果使用旧版浏览器或某些国产套皮浏览器出现界面错乱、功能异常等问题，请尝试更换为推荐浏览器。

**页面加载缓慢怎么办**：首先检查网络连接是否稳定，可以尝试刷新页面或清除浏览器缓存。如果问题持续存在，可能是服务器负载较高，建议稍后再试或联系管理员反馈。
