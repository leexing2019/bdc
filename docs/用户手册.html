用户操作手册

第一章 系统简介

1.1 产品概述

Smart Memo（智忆单词）是一款基于艾宾浩斯遗忘曲线理论开发的智能英语单词学习系统。该系统采用 Vue 3 前端框架构建，提供了流畅的单页应用体验，同时利用 Supabase 云数据库实现数据的实时同步，确保用户在任何设备上都能获得一致的学习进度。

本系统主要面向两类用户群体：一是教育机构的管理人员和教师，他们负责词库内容的管理和学生学习进度的监控；二是学生用户，他们通过系统进行单词学习和复习巩固。系统采用响应式设计，完美支持桌面端和移动端设备，让学生可以随时随地进行学习。

核心特性

  • 智能记忆算法：基于艾宾浩斯遗忘曲线，自动调整复习间隔
  • 实时数据同步：云端存储，多设备无缝衔接
  • 个性化学习：根据学生掌握程度定制学习计划
  • 批量导入：支持 Excel/TXT 批量添加单词

1.2 主要功能模块

管理端功能

  • 仪表盘：查看整体学习数据和动态
  • 词库管理：创建词库、添加/编辑/删除单词、批量导入
  • 用户管理：管理学生账号、分配学习词库、设置每日学习量
  • 学习计划：制定个性化学习任务
  • 统计分析：查看学习数据和分析报表

学生端功能

  • 今日学习：每日新词学习和复习任务
  • 单词本：查看和管理所有已学单词
  • 导入单词：添加个人感兴趣的单词
  • 个人中心：查看学习统计、调整设置

1.3 系统环境要求

系统推荐使用以下浏览器访问以获得最佳体验：

  • Google Chrome（版本 90 及以上）
  • Microsoft Edge（版本 90 及以上）
  • Mozilla Firefox（版本 88 及以上）
  • Safari（版本 14 及以上）
注意：请确保网络连接稳定，系统需要持续访问互联网以同步学习数据和获取在线资源。

第二章 快速开始

2.1 账号注册与登录

首次使用系统的第一步是注册账号。访问系统首页后，点击「注册」按钮进入注册页面。您可以选择使用邮箱注册或使用已有的社交账号快捷登录。填写必要的注册信息后，系统会向您的邮箱发送验证链接或验证码，请按照提示完成验证流程。

登录时，在首页输入注册时使用的邮箱和密码，点击登录按钮即可进入系统。如果忘记密码，可以点击「忘记密码」链接，通过绑定的邮箱接收重置链接。登录成功后，系统会自动跳转到对应角色的主页：管理员进入管理端，学生进入学习中心。

2.2 界面布局说明

进入系统后，您会看到清晰的界面布局。顶部是系统标题和当前登录用户的信息，点击用户名可以进入个人中心或退出登录。左侧（桌面端）或底部（移动端）是导航栏，包含系统的主要功能入口。中间区域是内容显示区，根据您选择的功能模块显示相应的内容。

提示：导航栏的设计遵循功能相关性原则，相关联的功能被组织在一起，便于快速定位所需功能。

第三章 管理端功能详解

3.1 仪表盘

仪表盘是管理员登录后的默认首页，提供了系统运行的核心数据概览。在这个页面，您可以快速了解当前的学习整体状况，包括注册用户总数、活跃用户数量、今日学习人数、累计学习单词数等关键指标。

仪表盘还展示了最近的学习动态列表，显示哪些学生最近有学习记录。这个列表是实时更新的，让您能够及时掌握学生的学习活跃度。

3.2 词库管理

词库管理是管理端最重要的功能之一，教师在这里管理和维护所有教学词汇资源。进入词库管理页面后，您可以看到现有的词库列表，默认包含 CET-4、CET-6 等常用词库，您也可以根据需要创建新的词库。

创建新词库

点击「新建词库」按钮，在弹出的对话框中输入词库名称，如「考研英语词汇」、「雅思核心词汇」等。您可以为新词库设置说明文字，描述该词库的适用场景和目标人群。创建完成后，新词库会立即出现在词库列表中。

添加单个单词

点击「添加单词」按钮，可以手动添加单个单词。添加单词时需要填写以下字段：

字段 必填 说明
单词拼写 是 英文单词，如 "hello"
词性 否 如名词(n.)、动词(v.)等
中文释义 是 单词的中文含义
音标 否 国际音标，如 /həˈloʊ/
例句 否 英文例句及中文翻译

批量导入单词

点击「批量导入」按钮，选择要导入的文件，系统支持 Excel（.xlsx、.xls）和纯文本（.txt）格式。导入前建议先下载系统提供的模板文件，按照模板格式准备数据可以提高导入成功率。

重要：Excel 文件需要按照规定的模板格式填写，第一行是表头，后续每行对应一个单词。错误的文件格式会导致导入失败。

批量更新例句

如果您的词库中缺少例句，可以使用批量更新例句功能。这个功能需要配置 DeepSeek API Key，配置后系统会自动为缺少例句的单词生成英文例句。注意使用此功能会产生 API 调用费用。

3.3 用户管理

用户管理页面展示了系统中所有注册用户的信息，包括学生和教师。管理员可以在这里进行用户账号的创建、编辑、删除和禁用等操作，也可以为学生分配学习词库。

分配学习词库

点击某个学生的「分配词库」按钮，选择要分配给该学生的词库（可以多选），学生登录后就会在单词本中看到被分配的词库内容。分配词库后，学生可以选择学习全部被分配的词库，也可以设置只学习特定词库。

设置每日学习量

在用户详情页面，管理员可以设置学生每天需要学习的新词数量。这个设置会影响学生每日学习任务的生成，合理的每日学习量可以帮助学生保持稳定的学习节奏。

3.4 学习计划

学习计划功能允许教师为学生制定个性化的学习任务。与简单的词库分配不同，学习计划可以精确控制每个词库每日的新词学习数量。

创建学习计划

在学习计划页面，点击「新建计划」按钮，选择目标学生和词库，设置每日学习数量（每日新词上限），还可以设置优先级。计划创建后立即生效。

3.5 统计分析

统计分析页面提供了丰富的学习数据分析功能，帮助教师了解教学效果和学生学习状况。包括：

  • 班级整体分析：平均学习天数、平均掌握单词数、遗忘率分析等
  • 个人学习详情：学习日历、各词库学习进度、记忆曲线变化等
  • 数据导出：支持将数据导出为 Excel 文件

第四章 学生端功能详解

4.1 今日学习

今日学习是学生端的核心功能，也是每天必用的功能。登录系统后会自动进入今日学习页面，这里展示当天需要学习的全部内容。

学习任务构成

每日的学习任务由两部分组成——新词学习和复习巩固。新词是指之前从未学习过的单词；复习是指之前学习过但还未完全掌握的单词。系统会根据艾宾浩斯遗忘曲线算法，计算每个单词的最佳复习时间。

学习流程

  1. 开始学习后，系统会以卡片形式展示单词
  2. 卡片正面显示单词和音标，可以点击发音按钮聆听读音
  3. 点击卡片可以翻转，查看中文释义和英文例句
  4. 根据掌握程度，选择「陌生」「模糊」「认识」或「掌握」按钮
  5. 不同的选择会影响下次复习的时间间隔

掌握程度说明

等级 说明 下次复习间隔
陌生 完全不认识这个单词 很短时间内再次出现
模糊 记得大概但不确定 较短间隔后出现
认识 看到这个单词能想起意思 较长间隔后出现
掌握 完全记住这个单词 很长的间隔后出现

4.2 单词本

单词本相当于学生的个人词库，存储了所有被分配的单词和自己导入的单词。在单词本页面，学生可以浏览、搜索、查看和筛选单词。

标签筛选

  • 全部：显示所有单词
  • 教师布置：老师分配的词库中的单词
  • 自行导入：自己添加的单词
  • 新词：从未学习过的单词
  • 学习中：正在学习的单词
  • 熟悉：已经熟悉的单词
  • 掌握：已经完全掌握的单词

搜索功能

如果单词较多，可以使用搜索功能快速定位。输入单词的英文或中文释义，系统会实时过滤显示匹配的结果。

4.3 导入单词

导入单词功能允许学生添加自己感兴趣的单词到个人词库。这个功能特别适合学有余力的学生，他们可以自主扩展词汇量。

手动添加

在导入单词页面，可以逐个添加单词。输入英文单词后，系统会自动从词典 API 获取音标、释义和例句。如果某些信息获取失败，也可以手动填写补充。

批量导入

如果需要一次性添加大量单词，可以使用批量导入功能。上传 Excel 或文本文件，系统会解析文件内容并批量添加单词。

4.4 个人中心

个人中心是查看个人信息和调整设置的入口。在个人中心，学生可以：

  • 查看学习统计（累计学习天数、总单词数、连续学习天数等）
  • 调整每日学习量
  • 切换主题模式（浅色/深色）
  • 管理个人资料

第五章 常见问题解答

5.1 账号与登录问题

忘记密码怎么办？

如果忘记了登录密码，可以在登录页面点击「忘记密码」按钮，输入注册时使用的邮箱地址。系统会向该邮箱发送密码重置链接，点击链接后设置新密码即可。如果收件箱没有收到邮件，请检查垃圾邮件文件夹。

收不到验证码怎么办？

请首先确认邮箱地址填写正确，然后检查垃圾邮件文件夹。某些邮箱服务商可能会拦截系统发送的邮件，可以尝试将发件地址加入白名单。如果持续无法收到，建议更换其他邮箱尝试。

5.2 数据同步问题

多设备登录数据是否同步？

是的，系统采用云端存储架构，所有学习数据都保存在云端。在任何设备上登录账号，都会自动同步最新的学习进度和设置。您可以在手机上开始学习，然后在电脑上继续，过程完全无缝。

5.3 学习相关问题

为什么认识的单词还会出现？

这是艾宾浩斯遗忘曲线的正常现象。系统会根据您对单词的掌握程度安排复习，即使当时选择了「掌握」，经过一定时间后系统仍会安排复习以巩固记忆。随着掌握程度的提高，复习间隔会越来越长。

每日学习量可以调整吗？

可以。在个人中心的设置页面，您可以随时调整每日新词数量。建议根据实际可支配的学习时间合理设置。

如何重置学习进度？

在个人中心设置页面底部，有「重置所有学习进度」的选项。点击后系统会提示确认，确认后所有学习记录将被清除。请注意这个操作不可恢复。
